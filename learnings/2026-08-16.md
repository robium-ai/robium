- [none] user-correction <!-- id: lrn-0816-14 -->
  symptom: `npm error 403 403 Forbidden - PUT https://registry.npmjs.org/robium-ai - Two-factor authentication or granular access token with bypass 2fa enabled is required to publish packages.`
  root-cause: `cli/.npmrc` always authenticates `doppler run -- npm publish` with the injected granular token; a write token with `bypass_2fa: false` was rejected rather than falling back to an interactive 2FA challenge.
  fix: use a narrowly scoped read-write granular token created with Bypass 2FA enabled for the current Doppler flow, or migrate releases to npm trusted publishing — check: `doppler run -- npm token list --json` exposed `bypass_2fa: false`, and the registry still reported `robium-ai@0.4.0` after the failed publish.
  dead-ends: relying on interactive 2FA while `NPM_TOKEN` is selected by the project `.npmrc` (the registry returned E403 without prompting).
